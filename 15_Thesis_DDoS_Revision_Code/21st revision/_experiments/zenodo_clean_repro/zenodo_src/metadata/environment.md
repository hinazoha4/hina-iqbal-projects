# Environment used to generate the deposited figures

Python packages, pinned to the versions that produced this deposit on 15 October 2026:

- numpy==2.5.1
- matplotlib==3.11.0
- pillow==12.3.0

Figures are written as PDF (vector), PNG, and LZW-compressed RGB TIFF at 300 dpi. The graphical abstract uses Matplotlib’s DejaVu Sans font, which ships with Matplotlib.

The training notebooks recorded a Kaggle GPU session (Python 3.12). This deposit does not reconstruct that session and does not retrain the models.
