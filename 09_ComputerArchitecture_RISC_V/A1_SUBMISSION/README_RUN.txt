============================================================
  HOW TO RUN (RARS)
============================================================

1. Open RARS (RUN_RARS.bat in computer architecture folder)
2. File -> Open -> t1a.asm  (this folder)
3. Run -> Assemble
4. Tools -> Bitmap Display
     Unit Width/Height  = 4
     Display Width/Height = 512   (for 128 x 128)
     Base address = Labels window mein "display" ka address
5. Connect to Program
6. Run -> Go

Expected: colorful surface image z = sin(x)*cos(y)

BEFORE UPLOAD:
- t1a.asm top pe APNA naam + student ID likho
- ZIP this folder (or just t1a.asm if only one file needed)
- Upload on inforestudante
